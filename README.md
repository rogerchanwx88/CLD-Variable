# CLD Variable Learning Coach — Naming Only

No API key, backend, subscription, student account, or paid AI service required.

## Use locally
Keep `index.html` and `guardrails.js` together in the same folder.
Open `index.html` in a browser.

## Update GitHub Pages
Upload BOTH `index.html` and `guardrails.js` into the ROOT of your GitHub Pages repository.
Commit the changes and wait for the site to redeploy.
If you previously uploaded only `index.html`, you MUST also upload `guardrails.js`.
Hard refresh the published page after redeployment.

## Feedback
- Acceptable naming: green tick and 'Variable is okay.' only.
- Naming issue: explanation, suggestions where available, and one reflective question.
- Ambiguous naming: clarification prompt and possible names.
- Does not evaluate causal links, loop polarity, archetypes, or student narratives.

This is a heuristic rule-based tool, not AI. Unknown terms are treated cautiously.
